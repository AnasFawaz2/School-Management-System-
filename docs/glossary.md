# Glossary

The interface is in Arabic only. These are the terms you will see in the screenshots.

| Arabic | English | Meaning |
|---|---|---|
| لوحة التحكم | Dashboard | The home screen of the signed-in user. |
| الحضور والغياب | Attendance | Recording who came to each session. |
| حاضر / غائب / متأخر / بعذر | Present / absent / late / excused | The four attendance states. An excused absence needs a reason. |
| التقدم الدراسي | Progress | Each student's progress, recorded by the teacher per session. |
| متابعة المنهج | Curriculum follow-up | Lessons taught and exams held per group. |
| تقييم الطلاب | Student evaluations | Growth of each student in nine areas. |
| لم يظهر بعد ← بدأ يظهر ← ثابت ← متميز | Not yet seen, starting, steady, outstanding | The four levels of an evaluation. They describe growth; they are not marks. |
| الأوسمة | Medals | Awarded when growth in an area is steady. |
| التخطيط | Planning | Monthly plans at school, section and group level, and notes between staff. |
| الملاحظات | Notes | Messages between staff, with *new / read / done* and a reply. |
| الاشتراكات | Subscriptions | Monthly fees per student. |
| تسديد / تسديد جزئي | Pay / partial payment | A full payment marks months paid; a partial payment is split evenly over its months. |
| غير مسدّد / مسدّد | Unpaid / paid | The state of a month. |
| متابعة المعلمين | Teacher follow-up | Follow-up notes by team leaders for their teachers. |
| الأعضاء | Members | Students and staff in one list. |
| المجموعات | Groups | A class: one teacher and its students. |
| التقارير الإدارية | Administrative reports | Reports written by administrators, with types and dates. |
| التقارير | Reports | Attendance and curriculum reports for the school, a group or a student. |
| سجل العمليات | Audit log | Who did what and when. |
| النسخ الاحتياطية والاستعادة | Backups and restore | Full backups and restoring from them. |
| الإعدادات | Settings | The school's name and logo. |
| الأرشيف | Archive | Where deleted items wait; they can be restored or deleted for good. |
| ولي الأمر | Parent / guardian | The family portal's user. |
| الرقم الخاص | School number | A student's or staff member's own number, from one shared series. |
| PIN | PIN | The 4-digit code a parent uses with the student's number. |
| مدير المدرسة | Director | Full access (the super admin role). |
| مشرف عام | General supervisor | Runs the school day to day (the admin role). |
| قائد قسم | Team leader | Supervises a set of teachers. |
| معلم | Teacher | Records attendance, progress and evaluations for their own groups. |
| ل.ل. (L.L.) | Lebanese pounds | The currency of the subscriptions. |
| السبت | Saturday | The class day, which drives the weekly reminders. |
